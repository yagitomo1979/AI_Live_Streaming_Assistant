# AI Live Streaming Assistant (YouTube + Local LLM + VOICEVOX)

## 概要
YouTube Liveのチャット欄を監視し、視聴者からのコメントに対してAIが自律的に思考・回答を行い、合成音声で読み上げる自動配信システムです。
Microsoftの `autogen` フレームワークを活用し、「プロデューサー（回答の方針決定）」と「ライター（実際の回答作成）」という2つのAIエージェントが内部で連携することで、より文脈に沿った質の高い回答を生成します。

## 主な機能
- **自律的AIディスカッション**: 視聴者のコメントに対し、プロデューサーAIが方針を指示し、ライターAIがそれに従って回答案（300文字以内・28文字改行）を作成します。
- **完全ローカルLLM駆動**: `llama-cpp-python` とカスタムクライアント（`LocalGGUFClient`）を使用し、GGUFフォーマットのローカルモデルで高速かつセキュアに動作します（モデルのキャッシュ機能付き）。
- **VOICEVOX連携**: 生成されたテキストをローカルで起動したVOICEVOXに送信し、自動で音声合成・再生（`pygame`）を行います。
- **配信用テキスト出力**: 最終的な回答テキストは自動的に `output.txt` に保存されます。OBS Studioの「テキスト(GDI+)」ソースでこのファイルを指定することで、配信画面にリアルタイムで回答を表示できます。

## 要件
- Python 3.x
- **VOICEVOX** (ローカル環境にインストールされ、起動していること)
- 動作可能なGGUFフォーマットのLLM

### 必須Pythonパッケージ
以下のコマンドで必要なライブラリをインストールしてください。
※GPU（CUDA等）を利用してLLMを動かす場合は、環境に合わせた `llama-cpp-python` のビルドが必要です。

```bash
pip install pygame pytchat pyautogen llama-cpp-python requests
セットアップ
スクリプトを実行する前に、コード内の以下の箇所をご自身の環境に合わせて編集してください。

1. LLMモデルパスの設定 (64, 65行目付近)
プロデューサー用とライター用のGGUFモデルの絶対パスを指定します。同一パスを指定した場合はキャッシュ機能によりメモリ消費を抑えられます。

Python
PRODUCER_MODEL_PATH = "/path/to/your/producer_model.gguf" 
WRITER_MODEL_PATH = "/path/to/your/writer_model.gguf" 
2. YouTube LiveのビデオID設定 (101行目付近)
監視したいYouTubeライブのURLに含まれる動画ID（v= の後の文字列）を指定します。

Python
VIDEO_ID = "YOUR_VIDEO_ID_HERE" 
3. (オプション) VOICEVOXのキャラクター変更 (53行目付近)
デフォルトでは speaker_id: 3（ずんだもん）に設定されています。必要に応じてVOICEVOXのキャラクターIDを変更してください。

使用方法
VOICEVOXの起動
事前にローカル環境でVOICEVOXアプリケーションを起動しておきます（エンジンが http://127.0.0.1:50021 で待機している必要があります）。

OBSの設定（テキスト表示を行う場合）
OBS Studio等の配信ソフトでテキストソースを追加し、「ファイルからの読み込み」にチェックを入れ、本スクリプトと同じ階層に生成される output.txt を指定します。

システムの起動
スクリプトを実行します。

Bash
python ai_live_system.py
コンソールに「YouTube Live [動画ID] に接続しました」と表示されれば準備完了です。最新のコメントを拾い、処理を開始します。

処理の流れ (ワークフロー)
pytchat が指定されたYouTubeライブから最新のコメントを取得。

コメントが autogen 経由で「プロデューサーAI」に渡され、回答のトーンや方向性を指示。

指示を受けた「ライターAI」が配信用のテキスト（文字数制限・改行制限あり）を生成。

完成したテキストを output.txt に上書き保存。

VOICEVOX APIへテキストを送信し、生成された音声を pygame で再生。

次のコメント待機状態へ戻る（高負荷を避けるため、一定の待機時間を挟みます）。

注意事項
YouTubeライブの仕様変更により、pytchat でコメントが取得できなくなる場合があります。その際はライブラリのアップデートを確認してください。

AIの推論中はCPU/GPUリソースを消費します。ゲーム実況など、他の重い処理と同時に行う場合はマシンスペックにご注意ください。
